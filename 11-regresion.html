Regresión: el error y cómo se reduce

Cómo se mide qué tan equivocado está un modelo, cómo el entrenamiento baja ese error paso a paso y por qué el error que importa es el de los datos nuevos.

Qué es el error de una predicción

Una regresión predice un número: el precio de una casa, la nota de un examen, la demanda de mañana. El modelo más simple es una recta, ŷ = m·x + b (la viste en el módulo 03). Para saber si la recta es buena, comparamos lo que predice con lo que pasó de verdad.

Para cada dato, el residuo o error es la distancia vertical entre el punto real y la recta:

eᵢ = yᵢ − ŷᵢ   (real menos predicho)

Si e es positivo, el modelo se quedó corto; si es negativo, se pasó. Ahora hay que resumir todos los errores en un solo número, para poder decir «esta recta es mejor que aquella». Sumarlos tal cual no sirve: un error de +5 y otro de −5 se cancelan y parecería que el modelo es perfecto. Hay dos arreglos:

MAE: error absoluto medio

MAE = (1/n) Σ |yᵢ − ŷᵢ|

El promedio de los errores sin signo. Se lee fácil: «en promedio me equivoco por 1.2 puntos».

MSE: error cuadrático medio

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Eleva cada error al cuadrado: castiga mucho más los errores grandes. Es suave, así que se puede derivar; por eso es la pérdida favorita para entrenar.

RMSE

RMSE = √MSE

Deshace el cuadrado para volver a las unidades originales (puntos, dólares, metros).

R²

R² = 1 − MSE / Var(y)

Compara tu modelo con el más tonto posible: predecir siempre el promedio. R² = 1 es perfecto y R² = 0 no mejora nada.

Ajusta la recta a mano y mira los cuadrados

Cada cuadrado tiene de lado el error de ese punto: su área es el error al cuadrado. El MSE es el área promedio. Mover la recta para que la suma de áreas sea mínima es exactamente el método de mínimos cuadrados.

Cómo disminuye el error: el entrenamiento

Para cada pareja (m, b) hay un MSE. Si dibujamos el MSE de todas las parejas posibles, obtenemos una superficie de error con forma de cuenco: el fondo del cuenco es la mejor recta. Entrenar es bajar al fondo, y para eso se usa el descenso del gradiente: mirar hacia dónde sube el error y dar un paso hacia el lado contrario.

Las derivadas parciales del MSE (módulo 07) dicen cuánto cambia el error al mover cada perilla:

∂MSE/∂m = −(2/n) Σ xᵢ·eᵢ     ∂MSE/∂b = −(2/n) Σ eᵢ

Se leen así: si los errores son mayormente positivos (la recta está por debajo de los puntos), la derivada respecto de b es negativa, y el paso b ← b − η·∂MSE/∂b sube la recta. Cada paso usa los errores actuales para corregirse un poco.

  1. Predecir con los valores actuales: ŷᵢ = m·xᵢ + b.
  2. Medir los errores eᵢ = yᵢ − ŷᵢ y el MSE.
  3. Calcular el gradiente: las dos derivadas de arriba.
  4. Dar un paso: m ← m − η·∂MSE/∂m y b ← b − η·∂MSE/∂b, con η la tasa de aprendizaje.
  5. Repetir hasta que el MSE deje de bajar.

Para la regresión lineal existe también un atajo exacto, sin pasos: la ecuación normal θ = (XᵀX)⁻¹Xᵀy, que usa las matrices del módulo 05. Es lo que hace el botón «Mostrar la mejor recta». En modelos grandes, como las redes neuronales, no hay atajo y solo queda bajar paso a paso.

Menos error en entrenamiento no siempre es mejor

Un modelo más flexible, como un polinomio de grado alto, siempre puede bajar más el error con los datos que ya vio. Pero puede estar memorizando el ruido en lugar de aprender la tendencia. Por eso se separan los datos: unos para entrenar y otros, que el modelo nunca vio, para probar. El error que importa es el de prueba.

Dónde aparece en ML

Todo entrenamiento sigue este guion: una función de pérdida que mide el error (MSE en regresión; entropía cruzada en clasificación), el descenso del gradiente para reducirla y un conjunto de validación para vigilar el sobreajuste. Las curvas de pérdida de entrenamiento y validación que verás en el curso son la gráfica de la derecha, contada en épocas en lugar de grados.

Pruébate

Errores de un modelo: 2, −2, 1, −1. ¿Cuánto valen la suma, el MAE y el MSE?

Suma = 0 (engañosa) · MAE = (2 + 2 + 1 + 1) / 4 = 1.5 · MSE = (4 + 4 + 1 + 1) / 4 = 2.5

Si la recta queda por debajo de casi todos los puntos, ¿qué signo tiene ∂MSE/∂b y hacia dónde se mueve b?

Los errores son positivos, así que ∂MSE/∂b = −(2/n)Σeᵢ es negativa. Como b ← b − η·(negativo), b aumenta y la recta sube.
