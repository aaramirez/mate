Límites y continuidad

La idea que sostiene todo el cálculo: a qué valor se acerca una función, aunque no pueda tocarlo. Sin límites no hay derivadas ni integrales.

¿A qué valor se acerca?

Toma f(x) = (x² − 1) / (x − 1). Si intentas calcular f(1) obtienes 0 / 0, que no significa nada. Pero puedes preguntar otra cosa: cuando x se acerca mucho a 1, ¿a qué valor se acerca f(x)?

Prueba con x = 0.9, 0.99, 0.999: obtienes 1.9, 1.99, 1.999. Y desde el otro lado, con 1.1, 1.01, 1.001: obtienes 2.1, 2.01, 2.001. Los dos lados se acercan a 2. Eso se escribe así:

límx→1 (x² − 1) / (x − 1) = 2Se lee: «el límite cuando x tiende a 1 es 2»

El límite no pregunta qué pasa en el punto, sino cerca del punto. Por eso existe aunque f(1) no esté definida. Se miran los dos lados: el límite por la izquierda (valores menores que el punto) y el límite por la derecha (valores mayores). Si coinciden, el límite existe.

Prueba

Acércate al punto desde los dos lados

Desliza el control hacia la derecha para acercarte: δ va de 1 a 0.001. Los puntos naranjas son f(a − δ) y f(a + δ). Un círculo vacío marca un valor que la función no toma.

La definición precisa: ε y δ

«Acercarse» suena vago. La definición formal lo vuelve un desafío entre dos personas. Una dice: «quiero que f(x) quede a menos de ε del límite L». La otra responde: «basta con tomar x a menos de δ del punto a». Si la segunda siempre puede responder, por pequeño que sea ε, el límite es L.

límx→a f(x) = L  ⇔  para todo ε > 0 existe δ > 0 tal que 0 < |x − a| < δ ⇒ |f(x) − L| < ε
Prueba

Pide un margen ε y mira qué δ hace falta

Función: f(x) = 0.5x² + 1, con a = 2 y L = 3. La franja azul es el margen ε alrededor de L. La franja naranja es la distancia δ alrededor de a. Mientras la curva dentro de la franja naranja no se salga de la azul, el desafío está ganado.

Límites al infinito y límites de sucesiones

También se puede preguntar qué pasa cuando x crece sin parar, o cuando avanzamos en una lista infinita de números. Esta segunda idea es la que convierte las sumas en integrales.

Cuando x crece

lím (x→∞) 1/x = 0

La fracción se hace tan pequeña como quieras, aunque nunca llega exactamente a 0.

La sigmoide

σ(x) → 1 si x → ∞; σ(x) → 0 si x → −∞

Por eso sus salidas sirven como probabilidades: nunca se salen de (0, 1).

Razón de funciones

lím (x→∞) (2x+1)/(x+1) = 2

El comportamiento que viste en el módulo 01, escrito como límite.

Una sucesión

1, 1/2, 1/3, 1/4, … → 0

Una lista infinita de números puede acercarse a un valor. Las sumas de Riemann S₁, S₂, S₃… hacen lo mismo con el área.

Continuidad: dibujar sin levantar el lápiz

Una función es continua en un punto a cuando no tiene saltos, huecos ni explosiones allí. En términos de límites, se piden tres cosas a la vez:

  1. f(a) existe: la función tiene un valor en el punto.
  2. El límite cuando x → a existe: los dos lados se acercan al mismo número.
  3. Los dos coinciden: límx→a f(x) = f(a).

Discontinuidad removible

un agujero

El límite existe pero no coincide con f(a), o f(a) no existe. Se arregla rellenando un solo punto.

De salto

izquierda ≠ derecha

Los límites laterales existen pero son distintos. Ejemplo: la función escalón.

Infinita

una asíntota vertical

La función crece sin límite al acercarse al punto. Ejemplo: 1/x en 0.

Vuelve al primer laboratorio: los casos «Continua» y «ReLU» cumplen las tres condiciones; los demás fallan al menos una. La lectura de abajo te dice cuál.

Dónde aparece en ML

La derivada se define con un límite, y la integral también. Para entrenar con descenso del gradiente la red debe ser continua: la función escalón del perceptrón original tiene un salto y su derivada vale 0 en casi todas partes, así que no da ninguna señal para aprender. Por eso se reemplazó por la sigmoide, que es continua y suave. ReLU es continua, aunque tiene una esquina en 0. Y el ε que ves en el código, como log(p + 1e-9) o a / (b + 1e-8), existe para esquivar asíntotas.

Pruébate

¿Cuánto vale lím (x→3) (x² − 9) / (x − 3)?

(x − 3)(x + 3) / (x − 3) = x + 3 → 6

¿Es continua f(x) = |x| en x = 0?

Sí: los dos límites laterales valen 0 y f(0) = 0. Tiene una esquina, pero no un salto.

¿Cuánto vale lím (x→∞) (3x + 2) / (x − 1)?

Ejercicios resueltos

Intenta cada ejercicio con lápiz y papel antes de abrir la solución.

1
Un 0 / 0 que sí tiene respuesta

Calcula límx→3 (x² − 9) / (x − 3).

Ver la solución paso a paso
  1. Si reemplazas x = 3 obtienes (9 − 9) / (3 − 3) = 0 / 0. Eso no es una respuesta: hay que reescribir la expresión.
  2. El numerador es una diferencia de cuadrados: x² − 9 = (x − 3)(x + 3).
  3. Para x ≠ 3 se puede cancelar el factor (x − 3), y el límite solo mira valores cercanos a 3, nunca el 3 mismo:
    (x − 3)(x + 3) / (x − 3) = x + 3
  4. Ahora sí se reemplaza: 3 + 3 = 6. Comprueba con números: x = 2.99 da 5.99 y x = 3.01 da 6.01.

Resultado: el límite es 6, aunque la función no está definida en 3.

2
Elegir k para que no haya salto

Sea f(x) = x² si x < 2, y f(x) = k·x si x ≥ 2. ¿Qué valor de k hace que f sea continua en x = 2? ¿Qué pasa si k = 3?

Ver la solución paso a paso
  1. Límite por la izquierda (x < 2, se usa x²): 2² = 4.
  2. Límite por la derecha (x ≥ 2, se usa k·x): k·2 = 2k. Además f(2) = 2k.
  3. Continua significa que los dos lados coinciden entre sí y con el valor de la función:
    4 = 2k → k = 2
  4. Con k = 3, por la derecha se llega a 6 y por la izquierda a 4. Los lados no coinciden: el límite no existe y hay una discontinuidad de salto de altura 2.

Resultado: k = 2. Con k = 3 la función salta de 4 a 6.

3
Ganar el juego ε-δ

Para límx→1 (2x + 1) = 3, el retador pide ε = 0.1. ¿Qué δ le respondes? ¿Y para cualquier ε?

Ver la solución paso a paso
  1. Queremos que la salida esté a menos de ε de 3: |(2x + 1) − 3| < ε.
  2. Simplifica: |2x − 2| = 2·|x − 1|. La condición queda 2·|x − 1| < ε.
  3. Divide entre 2:
    |x − 1| < ε / 2
  4. Con ε = 0.1 basta δ = 0.05. Comprueba: x = 1.04 da 2·1.04 + 1 = 3.08, que está a 0.08 de 3, menos que 0.1.

Resultado: δ = 0.05; en general δ = ε / 2 siempre gana.

4
Hacia el infinito

Calcula límx→∞ (3x² + 5) / (x² + 1), y luego los límites de la sigmoide σ(x) = 1 / (1 + e−x) cuando x → ∞ y cuando x → −∞.

Ver la solución paso a paso
  1. Divide arriba y abajo entre x², la potencia más alta:
    (3 + 5/x²) / (1 + 1/x²)
  2. Cuando x crece, 5/x² y 1/x² se acercan a 0. Queda 3 / 1 = 3.
  3. Sigmoide con x → ∞: e−x → 0, así que σ → 1 / (1 + 0) = 1.
  4. Sigmoide con x → −∞: e−x crece sin límite, el denominador se hace enorme y σ → 0.

Resultado: 3; la sigmoide tiende a 1 y a 0, sin tocarlos nunca.

En ML: por eso la sigmoide sirve para dar probabilidades. Su salida siempre queda entre 0 y 1 (módulo 03).

5
El piso del error

Al entrenar un modelo, el error después de n épocas sigue la sucesión en = 2 + 8 / n. Calcula e1, e4 y e100. ¿A qué valor converge el error?

Ver la solución paso a paso
  1. e1 = 2 + 8/1 = 10. e4 = 2 + 8/4 = 4. e100 = 2 + 8/100 = 2.08.
  2. Cuando n → ∞, 8/n → 0:
    límn→∞ (2 + 8/n) = 2
  3. El error baja cada vez menos: de 10 a 4 en tres épocas, y de 4 a 2.08 en noventa y seis más. Nunca baja de 2.

Resultado: 10, 4 y 2.08; el error converge a 2.

En ML: las curvas de pérdida se ven así. Cuando la curva se aplana cerca de su límite, entrenar más casi no ayuda, y ese es el momento de detenerse (módulo 11).
