Vectores: flechas y fichas de datos

Un vector es una lista ordenada de números. Se puede ver de dos formas: como una flecha en el espacio o como una ficha de datos. Una casa con 120 m², 3 habitaciones y 2 baños es el vector [120, 3, 2], una flecha en un espacio de 3 dimensiones.

La operación estrella es el producto punto: multiplicas posición por posición y sumas. Mide cuánto apuntan dos vectores hacia el mismo lado.

a · b = a₁b₁ + a₂b₂ = ‖a‖ ‖b‖ cos θ‖a‖ = √(a₁² + a₂²)
Prueba

Arrastra las puntas de las flechas

Pon las flechas en ángulo recto: el producto punto da 0. Ponlas en sentidos opuestos: da negativo.

Suma

[1, 2] + [3, 1] = [4, 3]

Posición por posición. Gráficamente, una flecha a continuación de la otra.

Por un número

2 · [1, 2] = [2, 4]

Estira o encoge la flecha sin cambiar su dirección.

Similitud coseno

cos θ = a·b / (‖a‖‖b‖)

1 = misma dirección, 0 = sin relación, −1 = opuestos.

Dónde aparece en ML

Cada ejemplo de un dataset es un vector. Los embeddings convierten palabras, imágenes o productos en vectores; los buscadores, recomendadores y sistemas RAG comparan esos vectores con similitud coseno. Y una neurona calcula exactamente un producto punto: w · x.

Pruébate

¿Cuánto vale [1, 2, 3] · [4, 0, −1]?

1·4 + 2·0 + 3·(−1) = 4 + 0 − 3 = 1

¿Qué largo tiene el vector [3, 4]?

√(9 + 16) = √25 = 5
