Vectores: flechas y fichas de datos

Un vector es una lista ordenada de números. Se puede ver de dos formas: como una flecha en el espacio o como una ficha de datos. Una casa con 120 m², 3 habitaciones y 2 baños es el vector [120, 3, 2], una flecha en un espacio de 3 dimensiones.

La operación estrella es el producto punto: multiplicas posición por posición y sumas. Mide cuánto apuntan dos vectores hacia el mismo lado.

a · b = a₁b₁ + a₂b₂ = ‖a‖ ‖b‖ cos θ‖a‖ = √(a₁² + a₂²)
Prueba

Arrastra las puntas de las flechas

Pon las flechas en ángulo recto: el producto punto da 0. Ponlas en sentidos opuestos: da negativo.

Suma

[1, 2] + [3, 1] = [4, 3]

Posición por posición. Gráficamente, una flecha a continuación de la otra.

Por un número

2 · [1, 2] = [2, 4]

Estira o encoge la flecha sin cambiar su dirección.

Similitud coseno

cos θ = a·b / (‖a‖‖b‖)

1 = misma dirección, 0 = sin relación, −1 = opuestos.

Dónde aparece en ML

Cada ejemplo de un dataset es un vector. Los embeddings convierten palabras, imágenes o productos en vectores; los buscadores, recomendadores y sistemas RAG comparan esos vectores con similitud coseno. Y una neurona calcula exactamente un producto punto: w · x.

Pruébate

¿Cuánto vale [1, 2, 3] · [4, 0, −1]?

1·4 + 2·0 + 3·(−1) = 4 + 0 − 3 = 1

¿Qué largo tiene el vector [3, 4]?

√(9 + 16) = √25 = 5

Ejercicios resueltos

Intenta cada ejercicio con lápiz y papel antes de abrir la solución.

1
Sumar y escalar

Con a = [2, −1] y b = [1, 3], calcula a + b y 3a − b.

Ver la solución paso a paso
  1. a + b = [2 + 1, −1 + 3] = [3, 2].
  2. 3a = [3 · 2, 3 · (−1)] = [6, −3].
  3. 3a − b = [6 − 1, −3 − 3] = [5, −6].

Resultado: a + b = [3, 2] y 3a − b = [5, −6]

2
Largo y distancia

Calcula ‖[6, 8]‖ y la distancia entre los puntos p = [1, 2] y q = [4, 6].

Ver la solución paso a paso
  1. ‖[6, 8]‖ = √(6² + 8²) = √(36 + 64) = √100 = 10.
  2. La distancia es el largo de la diferencia: q − p = [4 − 1, 6 − 2] = [3, 4].
  3. ‖[3, 4]‖ = √(9 + 16) = √25 = 5.

Resultado: 10 y 5

En ML: k vecinos más cercanos (módulo 12) usa exactamente esta distancia para decidir quién se parece a quién.

3
¿Perpendiculares?

¿Qué ángulo forman a = [1, 2] y b = [−4, 2]? ¿Y a con c = [−1, −2]?

Ver la solución paso a paso
  1. a · b = 1 · (−4) + 2 · 2 = −4 + 4 = 0. Si el producto punto es 0, cos θ = 0 y θ = 90°.
  2. c = −1 · a: es la misma flecha dada vuelta. a · c = −1 − 4 = −5.
  3. ‖a‖ = ‖c‖ = √5, así que cos θ = −5 / (√5 · √5) = −5 / 5 = −1, y θ = 180°.

Resultado: a y b forman 90°; a y c forman 180° (opuestos)

4
Embeddings y similitud coseno

Tres palabras tienen estos embeddings de juguete: gato = [2, 1, 0], perro = [2, 2, 1] y auto = [0, 1, 2]. ¿Qué palabra se parece más a «gato»? Usa √5 ≈ 2.236.

Ver la solución paso a paso
  1. Largos: ‖gato‖ = √(4 + 1 + 0) = √5 ≈ 2.236; ‖perro‖ = √(4 + 4 + 1) = √9 = 3; ‖auto‖ = √(0 + 1 + 4) = √5 ≈ 2.236.
  2. gato · perro = 2·2 + 1·2 + 0·1 = 4 + 2 + 0 = 6. Coseno = 6 / (2.236 · 3) = 6 / 6.708 ≈ 0.894.
  3. gato · auto = 2·0 + 1·1 + 0·2 = 1. Coseno = 1 / (2.236 · 2.236) = 1 / 5 = 0.2.
  4. 0.894 está mucho más cerca de 1 que 0.2.

Resultado: «perro» (≈ 0.894) se parece mucho más a «gato» que «auto» (0.2)

En ML: un buscador semántico o un sistema RAG hace esta misma cuenta con vectores de cientos de dimensiones.

5
Una neurona es un producto punto

Una neurona tiene pesos w = [0.5, −1, 2] y sesgo b = −1. Recibe la ficha de datos x = [4, 1, 0.5]. Calcula z = w · x + b y su salida con ReLU.

Ver la solución paso a paso
  1. Posición por posición: 0.5 · 4 = 2, (−1) · 1 = −1, 2 · 0.5 = 1.
  2. w · x = 2 − 1 + 1 = 2.
  3. z = 2 + (−1) = 1.
  4. ReLU(1) = 1, porque es positivo.

Resultado: z = 1 y la salida es 1

En ML: el peso negativo hace que la segunda variable reste en vez de sumar. Lo verás completo en el módulo 13.
